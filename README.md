# TJM – The Journey Matters

A Fabric mod (Minecraft 26.3) adding a custom **Journey** advancement tab and configurable Nether build rules.

Documentation: see the [wiki](https://github.com/JannisHeydemann/TJM/wiki) (sources in `docs/wiki/`).

## Build
`./gradlew build`
