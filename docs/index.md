# TJM – The Journey Matters

A Fabric mod that adds a custom **Journey** advancement tab and a few Nether rules.

## Requirements
| Dependency | Version |
|---|---|
| Minecraft | ~26.3 |
| Java | >= 25 |
| Fabric Loader | >= 0.19.5 |
| Fabric API | any |
| YetAnotherConfigLib (YACL) v3 | any |
| Mod Menu | optional (config screen) |

## Install
1. Install Fabric Loader for the Minecraft version above.
2. Put Fabric API, YACL and the TJM jar into your `mods` folder.
3. Start the game.
